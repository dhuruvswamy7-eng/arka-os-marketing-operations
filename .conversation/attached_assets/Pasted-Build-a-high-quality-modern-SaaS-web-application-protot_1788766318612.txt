Build a high-quality, modern SaaS web application prototype called ARKA OS — Marketing Operations CRM & Automation Platform for Arka Digital Media, a digital marketing agency.

This is a founder presentation prototype. The objective is to visually demonstrate how ARKA can replace its current highly manual marketing operations with one centralized internal platform.

IMPORTANT: This is NOT a generic CRM. This is NOT just a task manager. This is NOT just a content calendar.

It is a complete Marketing Operations Operating System that connects:

CLIENT MANAGEMENT → CAMPAIGNS → CONTENT PLANNING → CONTENT PRODUCTION → DESIGN → REVIEW → REVISION → APPROVAL → SCHEDULING → PUBLISHING → ANALYTICS.

The interface must look like a polished, production-ready SaaS product that could realistically be developed and used by an agency.

Use realistic sample data throughout the application so the founder can immediately understand how the system works.

SAMPLE AUTOMATION SCENARIO
Build one realistic end-to-end demo flow.

Scenario:

Client: ABC Restaurant

Content: Weekend Offer

Publishing Date: September 15

When the content is created:

Content status becomes Planned.

System creates Content Brief task.

After brief completion, Design Task is created.

Designer is automatically assigned.

Designer receives notification.

Deadline is calculated.

Designer uploads design.

Status changes to Manager Review.

Manager receives notification.

Manager requests changes.

Status changes to Changes Required.

Designer receives notification.

Designer uploads Version 2.

Manager approves.

Status becomes Approved.

Content moves to Scheduling.

Publishing occurs.

Status becomes Published.

Analytics record is created.

This workflow should be represented visually inside the prototype.
