BUILD ARKA OS — ROLE-BASED INTERNAL OPERATING SYSTEM

IMPORTANT:

Do NOT build all three roles with the same dashboard.

Do NOT give Founder, Manager and Team Member the same navigation.

Do NOT make this a generic task-management application.

ARKA OS is an internal operating system for Arka Digital Media where each role has a completely different responsibility.

The three roles are:

1. FOUNDER / ADMIN
2. MANAGER
3. TEAM MEMBER

Each role must have a different workspace, different navigation, different permissions, different dashboard, and different actions.

==================================================
CORE OPERATING MODEL
==================================================

The operational hierarchy is:

FOUNDER
    ↓
MANAGER
    ↓
TEAM MEMBERS

But the Founder can also directly assign work to a Team Member when required.

The normal operational flow is:

FOUNDER
↓
creates / assigns work
↓
MANAGER
↓
assigns specific work to Team Members
↓
TEAM MEMBER
↓
logs in
↓
starts work
↓
updates work
↓
reports progress
↓
submits for approval
↓
MANAGER reviews
↓
approves / requests revision
↓
MANAGER reports to FOUNDER
↓
FOUNDER sees overall operation
↓
FOUNDER can approve / comment / reassign / intervene

The system must represent this hierarchy.

==================================================
1. FOUNDER WORKSPACE
==================================================

The Founder is NOT an employee using ARKA OS to perform daily tasks.

The Founder uses ARKA OS to:

- See the entire company operation
- See who is working
- See who is logged in
- See login time
- See logout time
- See what each person is working on
- Assign work
- Assign work directly to Managers
- Assign work directly to Team Members when necessary
- Monitor deadlines
- Review reports
- Approve work/reports
- Comment
- Reassign work
- Identify blocked work
- Identify overloaded people
- Identify inactive/unassigned work
- See manager performance
- See team workload
- See operational bottlenecks
- Make decisions

The Founder should NOT have a "My Tasks" employee-style experience.

The Founder dashboard should be:

COMMAND CENTER
