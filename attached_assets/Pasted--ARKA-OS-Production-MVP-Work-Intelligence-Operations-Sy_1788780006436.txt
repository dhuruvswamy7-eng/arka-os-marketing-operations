# ARKA OS

## Production MVP — Work Intelligence & Operations System

You are the **Lead Product Engineer, Full-Stack Developer, and System Architect** responsible for building the first production-ready MVP of **ARKA OS** for Arka Digital Media.

This is NOT a design exercise.

This is NOT a static prototype.

This is NOT a collection of fake dashboards.

Build a **real, functional, secure internal web application** that Arka's team can actually use every day.

The MVP must have a clean architecture, real database persistence, authentication, authorization, task management, time tracking, operational visibility, and a founder command center.

---

# 1. PRODUCT PURPOSE

ARKA OS is an internal **Work Intelligence & Operations System**.

Its purpose is to give Arka one reliable system of record for:

* People
* Work
* Task ownership
* Priorities
* Deadlines
* Progress
* Time / effort
* Workload
* Bottlenecks
* Operational activity
* Founder visibility

The central product loop is:

**PEOPLE → WORK → ASSIGNMENT → DEADLINE → PROGRESS → TIME → WORKLOAD → BOTTLENECK → FOUNDER INSIGHT**

The MVP should answer these questions:

### For a Team Member

* What do I need to work on?
* What is due today?
* What is overdue?
* What is my priority?
* How much time have I spent?

### For a Manager

* What is my team working on?
* Who owns each task?
* What is due?
* What is delayed?
* Who has too much work?

### For the Founder

* What is happening across the company?
* Who is working on what?
* What is completed?
* What is overdue?
* Where is the workload concentrated?
* Where are the bottlenecks?
* What requires my attention?

# 10. DATABASE RULES

Every operational table should contain org_id where appropriate.

Use foreign keys.

Use indexes for:

* assignee_id
* due_date
* status
* priority
* org_id

Prevent negative durations.

Prevent invalid task states.

# 20. DEADLINE SYSTEM

If due date is future:

“3 days left”

“Due today”

“2 days overdue”

Handle timezone properly.

---

# 21. OVERDUE LOGIC

A task is overdue when:

due_date < current time/date

AND

status != DONE

Display overdue tasks clearly.

Founder and managers should be able to filter them immediately.
