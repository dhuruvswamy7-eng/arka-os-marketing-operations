BUILD ARKA OS — INTERNAL OPERATING SYSTEM FOR ARKA DIGITAL MEDIA

IMPORTANT:

This is NOT a generic task management application.

This is NOT a content calendar.

This is NOT a campaign management platform.

This is NOT an employee surveillance application.

ARKA OS is an internal operations system for Arka Digital Media.

The purpose is to manage:

PEOPLE
→ ATTENDANCE / PRESENCE
→ WORK
→ ASSIGNMENT
→ EXECUTION
→ PROGRESS
→ REVIEW
→ APPROVAL
→ REPORTING
→ LEAVE
→ TIME / EFFORT
→ WORKLOAD
→ FOUNDER VISIBILITY

The system must have three clearly separated role experiences:

1. FOUNDER / ADMIN
2. MANAGER
3. TEAM MEMBER

DO NOT give all three roles the same dashboard.

DO NOT give all three roles the same navigation.

DO NOT use hardcoded people names.

All users must come dynamically from the database.

==================================================
1. CRITICAL ROLE STRUCTURE
==================================================

The organizational structure is:

FOUNDER / ADMIN
        ↓
     MANAGERS
        ↓
   TEAM MEMBERS

Founder has organization-wide visibility.

Manager has visibility over their assigned team.

Team Member has visibility over their own work and own attendance/time.

Founder can:

- See all Managers
- See all Team Members
- See attendance/presence of all staff
- See work of everyone
- Assign work to Managers
- Assign work directly to Team Members
- Review reports
- Approve work where required
- Comment
- See workload
- See leave applications
- Approve/reject leave
- View historical attendance
- View work time
- View operational reports

Manager can:

- See their own team
- See team attendance
- See team login/logout
- See team work
- Receive work from Founder
- Assign work to Team Members
- Track progress
- Review Team Member submissions
- Request revision
- Approve Team Member work
- Comment
- Receive progress reports
- Create reports for Founder
- Escalate issues
- View team workload
- View team leave information

Team Member can:

- Login
- Logout
- See own attendance
- Apply for leave
- See leave status
- See assigned work
- Start work
- Track time
- Update progress
- Report progress
- Submit work for review
- Receive revision requests
- Complete work
- Comment
- See manager feedback

12. WORK TIME VS TASK TIME
==================================================

Keep these as separate concepts.

ATTENDANCE / SESSION TIME:

Time between login and logout.

WORK / TASK TIME:

Actual time logged against a Work Item or Task.

Founder should be able to see both.

Example:

Employee:

Login:
09:00 AM

Logout:
06:00 PM

Session duration:
09h 00m

Task time:
06h 15m

This allows the Founder to understand:

Presence time
and
Recorded work effort

without claiming that the difference represents inactivity or poor productivity.
