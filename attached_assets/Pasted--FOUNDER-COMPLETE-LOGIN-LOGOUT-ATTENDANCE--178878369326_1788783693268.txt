==================================================
FOUNDER — COMPLETE LOGIN / LOGOUT & ATTENDANCE
==================================================

THIS IS A MANDATORY FOUNDER FEATURE.

The Founder must have a dedicated:

ATTENDANCE & WORK TIME

page.

The Founder must be able to see the login and logout
records of EVERY employee in the organization.

This includes:

- All Managers
- All Team Members

Do NOT show only "Online / Offline".

Do NOT show only "Last active".

The Founder must see the ACTUAL LOGIN TIME and ACTUAL
LOGOUT TIME for every employee for every selected date.

==================================================
LOGIN EVENT
==================================================

Every successful authentication must create a login record.

Store:

id
organization_id
user_id
login_at
logout_at
session_duration_minutes
created_at

When the user logs in:

login_at = current timestamp

logout_at = NULL

When the user logs out:

logout_at = current timestamp

session_duration_minutes = calculated duration

==================================================
IMPORTANT LOGOUT BEHAVIOR
==================================================

Logout must be handled properly.

When the user clicks Logout:

1. Find the user's currently open login session.
2. Set logout_at.
3. Calculate session duration.
4. Save the session.
5. Then terminate the authentication session.

Do not simply terminate authentication without recording
the logout timestamp.

==================================================
ABANDONED SESSION HANDLING
==================================================

If a browser is closed or the user loses connection,
do not falsely create a logout time.

The system should distinguish:

LOGGED OUT

from:

SESSION STILL OPEN

Founder should see:

LOGIN:
09:05 AM

LOGOUT:
—

STATUS:
ACTIVE SESSION

For stale sessions, implement a safe session-presence
mechanism using last_active_at.

Do NOT invent a fake logout timestamp.

==================================================
ATTENDANCE VS WORK TIME
==================================================

IMPORTANT:

Do not combine attendance session time and task time.

ATTENDANCE SESSION TIME:

Login → Logout

TASK / WORK TIME:

Time actually recorded against Work Items / Tasks.

Founder must see BOTH.

Example:

Employee:

Login:
09:05 AM

Logout:
06:10 PM

Session Time:
09h 05m

Task Time:
06h 42m

These are separate measurements.

Do not automatically call the difference "idle time"
or "unproductive time".
